# Wheelwright Recipes

Wheelwright recipes is a recipe web application that allows any user to create, read, update, or delete recipes from it.

## Live Website

Visit the website at [wheelwrightrecipes.vercel.app](http://wheelwrightrecipes.vercel.app)

## Backend

The backend contains only a list of recipes for use in frontend. It is also hosted live at [wheelwrightrecipesapi.vercel.app](http://wheelwrightrecipesapi.vercel.app)
